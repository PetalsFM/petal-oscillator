# Prompts

Each file here is a complete first message for an assistant (whichever you use). Paste one in, attach or point at `include/petal/`, and describe your project in the blank at the end. Every prompt carries the calls it needs and the rules, so the assistant does not have to guess.

- `juce.md`: a JUCE synth plugin, one oscillator per voice.
- `vcv-rack.md`: a VCV Rack module with V/OCT, CV inputs and a polyphonic output.
- `madronalib.md`: a madronalib console app with no UI, played live or rendered to a WAV.
- `daisy.md`: firmware for an Electrosmith Daisy Seed or Pod.

If your host is not here, start from the one closest to it. The core only needs a sample rate and one call per sample.
